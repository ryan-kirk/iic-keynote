## Notes

- The current repo uses `NDVI` as the vegetation-index term; the earlier request spelled it `NVDI`.
- In the current deck, the precision-agronomy story uses real weather anchors but still uses an illustrative NDVI anomaly and illustrative as-applied context.
- The grain-logistics story mixes real statewide crop-progress anchors with an illustrative operating simulation because receipts, truck turns, and storage data are sensitive internal signals.
